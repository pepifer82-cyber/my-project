# A&T SLOT

Juego web móvil con créditos virtuales, cuentas de jugadores y consola administrativa.

- Juego: /slot/index.html
- Consola: /slot/admin.html
- Backend: Supabase + Edge Function `slot-play`
- Créditos iniciales: 10.000 ₲ virtuales
- Apuesta mínima: 100 ₲ virtuales
- La primera cuenta creada en el módulo Slot queda como administradora para habilitar la consola.

Este módulo está pensado como juego/promoción con créditos virtuales; no integra cobros, depósitos ni retiros de dinero real.
